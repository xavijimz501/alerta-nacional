- para compilar  descargar dependencias
mvn clean install

- para ejecutar
./mvnw spring-boot:run

- Abrir terminal y colocarse dentro de alerta-nacional
- Ejecutar java -jar target/meta-service.jar

- para ejecutar con Docker (Recomendado para usar en otras computadoras)
1. Asegurarse de tener Docker y Docker Compose instalados.
2. Ejecutar el siguiente comando en la terminal desde la raíz del proyecto:
   docker compose up --build
3. La aplicación se compilará y se iniciará automáticamente en http://localhost:8080
